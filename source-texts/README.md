# Public Domain Bibles

Clean, lossless, **plain-text** Bible translations that are in the public domain or freely licensed — one `.txt` file per translation, ready to read, search, align, or build on. No apps, no accounts, no OCR garbage: just the text.

## Why this exists

These translations are scattered across the web in inconsistent formats — some behind apps, some as bad OCR scans, some hard to even find. This is one tidy, version-controlled home for the plain text, so you own your copy and can use it offline. Freely give.

## Licensing

Each translation above is believed to be public domain or released under a permissive/public-domain dedication. Copyright status can vary by jurisdiction and edition — if you redistribute, verify the specific translation's terms. Copyrighted translations (NIV, ESV, NLT, and the *Easy-to-Read* Version — not to be confused with the public-domain English Revised Version here) are intentionally excluded.
